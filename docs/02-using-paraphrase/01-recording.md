# Recording and uploading

The three ways to add a take to a project, and how long one can be.

## Recording in the browser

Press Record in a project and allow the microphone when the browser asks. The take is saved to the project as you record, a few seconds at a time, so closing the tab or losing the connection does not lose what was already sent. If the connection drops, the recorder says how many seconds are waiting to be saved and sends them when it comes back.

## Uploading a file

Upload an audio or video file you already have. Most formats work, because the file is read by the same media tools that cut it later.

For a video, the sound is taken out in your browser and uploaded on its own, so a large video is not sent just to be transcribed. The picture is only uploaded if you export the project as MP4.

## Bringing in a link

Paste a link to audio or video and the file is fetched on our side, without you downloading it and uploading it again.

## Languages

Transcription covers 25 European languages and detects which one it is hearing: Bulgarian, Croatian, Czech, Danish, Dutch, English, Estonian, Finnish, French, German, Greek, Hungarian, Italian, Latvian, Lithuanian, Maltese, Polish, Portuguese, Romanian, Russian, Slovak, Slovenian, Spanish, Swedish and Ukrainian.

## How long a recording can be

A recording can be from half a second to four hours long. A project also has a total length, which depends on your plan: see [Credits, plans and limits](/docs/credits-and-plans).

Transcribing a recording costs one credit per second of audio, rounded up to the second. If a recording fails for a reason on our side, its credits are returned.
